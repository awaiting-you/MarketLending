# СДВИГ — лендинг маркетингового агентства

**Одной строкой:** одностраничный лендинг агентства полного цикла на Next.js — тёмная тема с неоновым акцентом, анимации по скроллу и форма заявки, собранная без бэкенда.

**Живая версия:** <https://market-lending.vercel.app> · исходники: [`awaiting-you/MarketLending`](https://github.com/awaiting-you/MarketLending)

## Что сделано

- Продающая структура: оффер → услуги → кейсы с метриками → тарифы → отзывы → форма
- Своя система анимаций на IntersectionObserver: появление секций по скроллу и анимация счётчиков — без GSAP и Framer Motion
- Форма заявки с клиентской валидацией и маской телефона: без бэкенда, payload уходит в консоль, показывается экран подтверждения
- Дизайн-токены на CSS (Tailwind v4, CSS-first `@theme`): тёмная тема, неоновый лайм, адаптив от 320 px
- SEO: мета-теги, Open Graph с генерируемой картинкой 1200×630, JSON-LD, sitemap и robots
- Доступность: семантика, видимый фокус, `prefers-reduced-motion`, контент виден и без JS

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · next/font (Onest + Manrope)

Собирается в статику — задеплоится на Vercel или любой Node-хостинг без сервера.
